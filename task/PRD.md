# PRD：exchange-core 综合吞吐优化

## 目标

在固定 Linux AMD64 环境中，提高 exchange-core 在多交易对、保证金、现货和中等规模多交易对负载下的综合吞吐量，并保持原有功能、状态与接口兼容。

## 功能要求

- R1：项目可构建、引擎可启动并正常关闭。
- R2：订单创建、移动、撤销、成交及优先级规则保持正确。
- R3：账户、余额、费用、保证金和风险拒绝保持正确。
- R4：订单簿、全局余额及状态哈希保持一致和确定。
- R5：公开API、配置、报告和序列化行为保持兼容。
- R6：非法输入、余额不足、重复请求和异常路径行为保持正确。
- R7：多种固定工作负载下的综合吞吐量高于初始基线。
- R8：提交产物不包含测试篡改、固定输出或Verifier绕过行为。

## 非目标

- 不要求增加交易业务功能；
- 不要求复制某一参考优化补丁；
- 不以代码行数、提交次数或运行时间本身作为得分。
