# 公开评测约定

## 评分对象

每次提交只收集：

```text
src/main/
src/main/resources/
pom.xml
.mvn/
```

测试文件、评分脚本和其他目录不会从Agent工作区进入评分环境。

## 评测组成

1. Test Case：构建、撮合、风险、账户、状态、兼容、边界和回归，单条结果为0或1。
2. Metric：多个固定工作负载下的吞吐量，归一化至 `[0,1]`。
3. 硬门槛：构建失败、关键回归、状态不一致、数据破坏或完整性违规。

## 反馈边界

反馈可以公开测试分组、当前指标、归一化得分、回归和约束状态，但不会公开隐藏输入、随机种子、参考实现、准确修改位置或直接优化方案。
